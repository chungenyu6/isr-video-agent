Live demo

範圍

  • 綁 127.0.0.1:8090，SSH tunnel 使用，永不公開
  • 只選 clip（12 支）與 seed，不接受自由文字 → 沒有 prompt injection 入口
  • 一次一個 run；模型未啟動時顯示警告
  • 標示 “Live demo run — not experiment evidence”

如何不碰實驗 repo

  • Demo 自帶 runner，唯讀使用實驗的 prompt、tools、Pi 設定、evaluator
  • 每次執行前比對 freeze.json hash，不一致就拒絕
  • Run 寫入 live/runs/（gitignored），不寫 manifest，不佔 64-run 預算
  • 產生的指令與正式 command.sh 比對（run_id／seed／路徑以外必須相同）

可能需要系統權限：agent 以 phase0agent 執行，需要能寫 live/runs/ 但讀不到 GT。若要改 repo 以外的 ACL，會先停下來說明。
